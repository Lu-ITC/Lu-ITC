## Selected public work

### Accountable automation

- **[approval-gate-mcp](https://github.com/itcustomsolution/approval-gate-mcp)** adds human approval requests, expiry and single-use consumption to an MCP workflow. Enforcement belongs in trusted execution code; the gate is not protection against an agent with the same OS-user privileges. [Release v0.4.0](https://github.com/itcustomsolution/approval-gate-mcp/releases/tag/v0.4.0).
- **[task-handoff-check](https://github.com/itcustomsolution/task-handoff-check)** checks a JSON handoff for a named owner, next action, blockers and evidence references. A pass establishes structural consistency, not that the work is complete. [Release v0.1.1](https://github.com/itcustomsolution/task-handoff-check/releases/tag/v0.1.1).
- **[delivery-evidence-check](https://github.com/itcustomsolution/delivery-evidence-check)** compares local files against a SHA-256 manifest. Integrity is useful evidence only when the manifest is trusted; it is not proof of authorship or correctness. [Release v0.2.0](https://github.com/itcustomsolution/delivery-evidence-check/releases/tag/v0.2.0).

### Practical procurement tools

- **[sam-gov-mcp](https://github.com/itcustomsolution/sam-gov-mcp)** exposes read-only public opportunity search through MCP using the operator's SAM.gov API key. It does not rank opportunities or submit bids. [GitHub v0.2.1](https://github.com/itcustomsolution/sam-gov-mcp/releases/tag/v0.2.1); npm remains at 0.2.0 as of 26 October 2026.
- **[bid-deadline-check](https://github.com/itcustomsolution/bid-deadline-check)** extracts deadlines and requirements locally from text and PDFs. Its conservative rules usually require human review of real solicitations. [Release v0.2.0](https://github.com/itcustomsolution/bid-deadline-check/releases/tag/v0.2.0).
- **[govcon-smallbiz-toolkit](https://github.com/itcustomsolution/govcon-smallbiz-toolkit)** provides bid/no-bid, SAM.gov registration and IT-security checklists, with an optional agent-skill format. Its checks validate packaging, not an assistant's judgment.

All six projects carry MIT licenses in their repositories. The software releases above are early 0.x versions; their READMEs distinguish released packages from development work and link verification evidence.
